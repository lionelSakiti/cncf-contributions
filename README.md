## Méthode de suivi

1. Ajouter une entrée uniquement lorsque la preuve est consultable sans accès privé.
2. Utiliser un statut précis : **proposé**, **en cours de revue**, **fusionné**, **publié**, **présenté**.
3. Ne jamais qualifier un fork personnel de contribution upstream fusionnée.
4. Conserver les dates vérifiées et mettre à jour le statut au fil du temps.
5. Exclure les données internes d'employeurs et les informations personnelles de tiers.
